Scenario settings

The Scenario menu holds the map's own tables. Each dialog is its own OK / Apply / Cancel transaction, and what an OK or Apply wrote is one undo step: Ctrl+Z after closing the dialog takes the whole of it back, and Ctrl+Y puts it on again.

Map Properties, Players, Forces, Colours#

Map Properties (Alt+Enter) is the name and description the lobby shows, the tileset, the size and the revision, with buttons to the rest.

Changing the tileset lays the terrain again with a terrain you pick — tile numbers mean something else in every tileset — and drops the doodads, while units, sprites, locations, fog and triggers stay. You can also keep the tile numbers, to see what they draw in the new tileset. Resize / Crop Map… grows or trims the map about a corner or the centre. Both clear the undo history.

Player Settings is each slot's controller (Human, Computer, Rescuable, Neutral…), race, colour and force.

Force Settings groups the players into up to four teams and sets, per team, allied victory, shared vision, allies and random start locations.

Player Colors picks each slot's palette colour and, for Remastered, a custom RGB, random, or the player's own choice; the map repaints as you change them. What the game shows depends on the map's revision:

  • Brood War and Remastered 1.21+: the game reads the palette colours. Only the first twelve work as a palette colour: for the rest StarCraft 1.16.1 shows a wrong colour and Remastered the player's usual one, and Tools ▸ Check Map says so.
  • StarCraft 1.00, Hybrid and Remastered without Brood War: StarCraft 1.16.1 shows every player in their slot's usual colour, whatever the map says. Remastered takes the colours from its own colour table, which the editor writes whenever a colour is not the slot's own.

In Remastered, a custom RGB gives the player any colour, those ten included. Random and the player's own choice both show as Random in the lobby, the player's choice as a list the player can change, and a player left on Random gets a different colour each game.

Units, upgrades and technology#

Unit Settings, Upgrade Settings and Technology Settings edit the cost and availability tables:

  • a unit's hit points, armour, build time, cost and weapon damage, a custom name, and which players may build it;
  • an upgrade's cost and levels;
  • a technology's cost, and whether each player starts with it or may research it.

A row on use default shows the game's own numbers greyed out, and starts from them when you untick it.

Strings#

Every piece of text a map carries — its name, the force names, location names, every trigger message — is a numbered string, and the String Editor lists them all with where each is used. Edits keep their number, so triggers and locations keep pointing where they did; Delete unused clears out what nothing refers to.

The row of buttons inserts the game's colour codes, each drawn in the colour it produces, and the preview under the box shows the string the way the game draws it. The same codes work in every field whose text the game draws: the map name and description, force names, custom unit names, and the text of a trigger or briefing action. Each of those fields shows the string as the game draws it until you click into it, and has a palette button at its right-hand end.

The previews follow Remastered's rule, where a colour set on one line carries onto the next. StarCraft 1.16.1 reset the colour at every line break, so an older map's text can show in colours its author did not choose. The 1.16.1 colours tick (also in Preferences ▸ View) switches every preview to the old rule, and the Repair plugin offers to write the resets the old game supplied. Two codes do something you might not expect, in both games: <01> goes back to the colour before the last change rather than to the default, and once the text is grey (<05>) the game ignores every later colour code in the string. The previews follow both.

File ▸ Export ▸ Strings (.txt)… writes every string to a numbered text file, and File ▸ Import ▸ Strings (.txt)… reads such a file back, replacing the strings by number — a way to translate or proofread a map's text outside the editor.

Text that looks garbled. If a map's text opens as nonsense, often Korean or Japanese text in an older map, the editor guessed its encoding wrong. A map file does not say what encoding its text is in, so the editor guesses from the bytes when the map opens. Open Scenario ▸ Map Revision…, choose the right encoding (Korean, say), and every string is fixed at once. The same choice decides how the text is written on save, so a map made for 1.16.1 on a Korean Windows stays readable there. A new map is UTF-8, which Remastered reads, and a map moved to Remastered's string table becomes UTF-8 too. Western text saved as Windows-1252 can go wrong in Remastered, which reads some of it as Korean: "Ärger Don’t" shows as "훣ger Don뭪" (see the string table). Text saved as UTF-8 always shows as written. A character the chosen encoding cannot hold is saved as ?; Check Map and the Save dialog say so beforehand.

Sounds and switches#

The Sound Editor lists the map's sounds with the .wav files in the archive: import, play, remove, and adopt files the archive carries but the list does not. Import takes any file the browser can decode (MP3, FLAC, AAC, Ogg, WAV in any encoding) and writes it as a WAV in the format picked next to the button. The default, 22050 Hz 16-bit mono, is what the game's own sounds are; the smaller presets are for maps near the size limit. A Play WAV action then names the file. Some maps made for Remastered carry Ogg sounds instead; Remastered plays them in a map of any revision, while StarCraft 1.16.1 stays silent, and Check Map points them out.

A trigger can also play one of the game's own sounds, a unit's voice or an interface click, without the file being in the map. In the Trigger Editor, Browse… beside a WAV argument lists the map's sounds and the game's together. Search by file name, by unit, or by when the unit says the line: "marine yes" finds the four things a Marine says when ordered. In a Transmission the list opens on the lines of the unit the action already names. The line under the field says what the path is, and warns when it is neither in the map nor one of the game's. The list does not play the sounds.

Switches names the 256 switches triggers set and test, so the trigger editors show "Gate open" rather than "Switch 3".
