Getting started

There are three ways to run scmJS, each covered in docs/installing.md:

  • In the browser at scmjs.dev/editor. Nothing to install, and your maps stay on your own disk.
  • As a desktop app for Windows, macOS and Linux, from the releases page. It finds a StarCraft installation on its own and opens a map on a double-click.
  • In a container, for a server on your own network: docker run --rm -p 8080:80 ghcr.io/scm-js/scm-js:latest, then open http://localhost:8080.

The game's graphics#

StarCraft's graphics do not ship with the editor. On first use it asks where to get them, and the recommended answer is your StarCraft folder: the classic game (1.16) or StarCraft: Remastered. Choose Choose the StarCraft folder… and pick the folder the game is installed in, usually C:\Program Files (x86)\StarCraft. The browser asks whether to upload the folder; nothing leaves your computer, the files are only read. The desktop app looks for an installation on its own, and has a Search this computer button as well. Picking a Remastered folder also turns on Remastered graphics.

Without StarCraft installed, the dialog offers Blizzard's free StarCraft map editor download (83 MB), which carries the graphics. You can also pick StarDat.mpq and BrooDat.mpq from a classic installation by hand. What each source allows:

Where the files come from Edit maps Watch replays Test or play on scmjs.dev
Your StarCraft folder, classic or Remastered Yes Yes Yes
StarDat.mpq and BrooDat.mpq from a 1.16 installation Yes Yes Yes
Blizzard's map editor download Yes Yes No

The files are read once and a copy is kept for next time. The graphics has the steps in full. Without any graphics the editor still runs, with terrain in flat colours and units as coloured markers.

Help ▸ Game Data… opens the same dialog later. It shows where the current copy came from and can remove it. Under Data sets it installs a mod's files beside the game's and switches between them, and offers Add StarCraft: Remastered… when you have a classic copy and no Remastered one. A tick keeps the extra files the play page needs for real-time lighting (about 200 MB more). Data sets explains how mods are installed.

Opening a map#

  • Ctrl+O (File ▸ Open…) opens a .scm, .scx or .chk file, and so does dropping one on the window.
  • File ▸ Open Recent lists what you have had open before. In Chrome, Edge and the desktop app it reopens the file straight from disk.
  • File ▸ Find on scmscx.com… searches the community map archive and opens the map you pick. A link like https://scmjs.dev/editor/scmscx/35b32Dsq, with the id from the map's address on scmscx.com, opens the editor with that map picked.
  • File ▸ Open from scmjs.dev… lists the maps kept on your scmjs.dev account, with every revision you saved (see Your scmjs.dev account).
  • File ▸ Open Replay… opens a replay over the map it was played on (see Replays).

A map opens in its own tab, beside the ones already open (see The editor window). The blank map the editor starts on is the exception: the first map you open takes its place.

A map that is damaged, or that a map protector has altered, is checked and repaired as it opens. See Damaged and protected maps.
