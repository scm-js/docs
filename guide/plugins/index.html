Plugins

Plugins add tools to the editor, and several of the tools in this guide are plugins. Most come installed and on; a few more are a click away in Plugins ▸ Browse Plugins….

Plugin Starts Where What it does
Aftermath On File ▸ Open Replay… Opens replays over their map; see Replays
Paint On Tools ▸ Paint… (Ctrl+Shift+P) Lines, shapes, spray and text, from the palette's pick
Repair On Tools ▸ Repair Map… Repairs damaged and protected maps as they open
scm-sim On Tools ▸ Test Map in Browser Plays the map on scmjs.dev/play
scmjs.dev On Account menu Your scmjs.dev account
scmscx.com On File ▸ Find on scmscx.com… Searches the scmscx.com map archive
Stamp Library On Tools ▸ Stamp Library… (Ctrl+Shift+L) Pieces of map kept across maps
Terrain from Image On File ▸ Import ▸ Terrain from Image… Turns a picture into terrain
TrigScript On Triggers ▸ TrigScript… Triggers as code; see TrigScript
Walkability On View ▸ Walkability (Ctrl+Shift+W) The ground as a unit walks it
TrigEdit Off Triggers ▸ Text Trigger Editor… (Ctrl+Shift+T) Triggers as SCMDraft text
Magenta Browse Triggers ▸ Magenta… Triggers as sentences, with Remastered EUD
Melee Wizard Browse Tools ▸ Melee Wizard… (Ctrl+Shift+M) Start locations and mineral lines
Section Explorer Browse Tools ▸ Section Explorer… (Ctrl+Shift+H) The map file, section by section and byte by byte
Timelapse Browse View ▸ Timelapse… Records the map as you build it
Trigger Map Browse Triggers ▸ Trigger Map… The triggers as a graph

On plugins are installed and running; Off is installed but needs ticking on in Plugins ▸ Manage Plugins…; Browse is installed from Plugins ▸ Browse Plugins….

A few that need more than a line:

  • Paint lays down whatever the active layer's palette has picked, so it paints units, doodads, sprites, terrain or fog depending on the layer.
  • Stamp Library keeps named pieces — a ramp, a bridge, a cliff corner, a mineral line — in the browser's storage. Click one and it hangs under the pointer, drawn with the map's graphics; click to lay it down. Stamps can be searched, tagged, exported and shared as a line of text.
  • Melee Wizard lays out symmetric start locations, and mineral lines and geysers at the distance the game mines fastest from, with presets for main, natural and third, a symmetry check and a resource summary.
  • Timelapse records one frame per change and plays the recording back with a box around each change. Export it as a GIF or a WebM video. Opening the same file again carries on the same recording.
  • scm-sim is the game engine behind the play page. Besides Test Map in Browser, it is what Aftermath and Walkability use to have the game play a replay or walk a map. It works only in the editor at scmjs.dev.

Each plugin's own README, linked in the table, has the details.

Adding and managing plugins#

Plugins ▸ Browse Plugins… lists the plugins the project publishes; press Install on one and it shows where the code comes from before adding it. The plugins listed there are reviewed before they are listed.

Plugins ▸ Manage Plugins… lists what is installed, turns each on or off, and takes the address of any other plugin: a GitHub repository, a link to its plugin.json, or http://localhost:3000/ while you write one. A plugin that has settings keeps them on its own page under Edit ▸ Preferences ▸ Plugins.

There is no sandbox: a plugin has the same access as the editor itself, so only add plugins you trust. The Add screen shows the manifest, the repository and the addresses the plugin will fetch from.

Browse Plugins also lists two plugins for people writing their own: Hello World, an example with nothing in it but a Tools menu item, and the API Playground, a code editor for trying the plugin API on the open map. Installing plugins, what they are allowed to do, and writing one are covered in docs/plugins.md.
