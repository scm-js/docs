Command line

scmjs in a terminal: what a map or replay holds, Check Map and maps as text for git and CI, a map's triggers run in the game, a replay watched in the terminal, and the same commands as an MCP server for AI tools.

scmjs is scmJS on the command line. It reads and writes map files with the editor's own code, so the two agree about every map, and it does what a terminal is good for:

  • Maps. What a map holds, Check Map over any number of maps, a new map, a search across maps, the Scenario menu's edits, a map's archive as a folder and back.
  • Maps in git and CI. A map as text so git diff shows what changed, triggers and strings as files beside the map, what differs between two maps or two revisions, Check Map's findings as the annotations a pull request shows, commands that chain in a pipe.
  • The game. A map's triggers run in the game itself to see which fire and what they cost, the distance between its start locations walked by the game's own pathing, a replay played in the terminal, a map drawn with the game's own graphics, a TrigScript map built as Save builds it, a plugin run over a map with no editor around it.
  • AI tools. The same commands as an MCP server, so Claude Code and its like can read, check and change your maps.
  • Plugins and bots. A plugin started, checked and reloaded on every save; a BWAPI bot of your own built for the play page and played from the terminal.

You need Node.js 22.12 or newer. Install it once, and type scmjs from then on:

npm install -g @scm-js/cli
scmjs info "(2)Destination.scx"

Or run it without installing, with npx, which fetches it the first time: npx @scm-js/cli info "(2)Destination.scx". Every command has --help, and scmjs on its own, or scmjs --help, lists them all beside the scmJS globe.

To update an installed copy, run npm install -g @scm-js/cli@latest. scmjs about says when there is a newer version.
