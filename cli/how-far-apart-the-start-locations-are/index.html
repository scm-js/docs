How far apart the start locations are

scmjs map rush measures how long a rush takes between each pair of start locations. The game itself walks a unit from each start location to every other, by the way a unit sent there in a game would take, and times each walk. An SCV is walked unless you name another unit with --unit, by its name in the editor ("Zerg Zergling"), without the race (Zergling, Dragoon) or by its number in units.dat. The table has the starts as rows (walked from) and columns (walked to), each with where it is on the map as a clock face from the middle:

$ scmjs map rush "(4)Fighting Spirit.scx" --unit Zergling
(4)Fighting Spirit.scx 128 × 128, jungle · 4 start locations · a Zergling walked 12 times · Remastered files
  1 → 2  4,722 px, 38.0 s
  …

✔ (4)Fighting Spirit.scx: a Zergling walked between 4 start locations by the game · 12 walks · 4.0 s

  from ╲ to                    1                 2                 3                 4
  1 1 o'clock                  –  4,722 px, 38.0 s  5,553 px, 45.7 s  4,543 px, 37.0 s
  2 11 o'clock  4,793 px, 38.6 s                 –  4,674 px, 37.3 s  5,658 px, 45.4 s
  3 8 o'clock   5,560 px, 45.0 s  4,875 px, 39.1 s                 –  4,697 px, 37.7 s
  4 4 o'clock   4,596 px, 37.4 s  5,770 px, 45.9 s  4,686 px, 37.6 s                 –

  Shortest 1 → 4: 4,543 px (142 tiles), 37.0 s · air 3,520 px, 1.29× the straight line
  Longest  4 → 2: 5,770 px (180 tiles), 45.9 s · air 5,001 px, 1.15× the straight line

The pixels are what the unit walked (32 to a tile) and the seconds are game time at Fastest. The unit sets out five tiles from its start toward the middle of the map and stops at the edge of the town hall at the other start — a neutral Nexus stands on every start while the walks run, so the way ends where a real rush ends, at the base. The two directions between a pair can differ by a second or so: the way out of each base is not the same. The shortest and longest walks are set beside the straight line between the two start locations, the distance a flyer goes. When the terminal is too narrow for both figures, the seconds and the pixels come as two tables.

A walk that does not arrive is a finding too. Two starts with no ground between them — an island map, or ground the terrain walls off — are said to have no way; on a map where no two starts are joined, the report says so and lists the straight lines instead. A unit that stops short (a wall of minerals or buildings the map places, say), stands stuck, or is still walking after seven minutes of game time is named with how far from the base it ended.

The walks run in one game, with nobody else in it; about four seconds for a four-player map and fifteen for an eight-player one of 256 × 256. --seed changes the game's luck (a unit stepping round another); the default is the one the editor's Walkability plugin uses, so the two agree. --json gives every walk and the matrix as data. A building or a flyer is refused (exit 2), as is a map with fewer than two start locations. Like map trace, it needs the game engine and your own copy of StarCraft (what those commands need); a map in the StarCraft 1.00 form is walked as Brood War.
