scmJS documentation

scmJS is a StarCraft: Brood War map editor that runs in a browser tab or as a desktop app. It opens, edits and saves StarCraft maps: .scm, .scx and .chk files and reads .rep files.

The latest version of the editor is always available at scmjs.dev/editor.

See the getting started page for more information.

What it does

Beyond the terrain, units, locations and triggers every StarCraft editor has, scmJS does the following. Items marked Browse Plugins are one click away under Plugins ▸ Browse Plugins… rather than installed from the start.

  • Classic or Remastered graphics. Pointed at a Remastered installation, the editor draws with Remastered's terrain, units and moving water; View ▸ Remastered Graphics switches back. See Classic or Remastered graphics.
  • Replays. File ▸ Open Replay… opens a .rep on the map it was played on, with the players' orders on a timeline, build orders and the chat. At scmjs.dev the game also plays back and is analysed: fights, economy and tech. See Replays.
  • Test in the game or the browser. Tools ▸ Test Map puts the map in the game's Maps folder; at scmjs.dev, Tools ▸ Test Map in Browser plays it in a browser tab from your own StarCraft files. See Test Map.
  • Several people on one map. Share the open map and anyone with the link edits it with you, live. See Editing a map together.
  • Triggers as code. TrigScript writes triggers in TypeScript, with tests and a simulator; for Remastered it also builds code that runs in the game itself.
  • AI on your own key. With your Anthropic API key, an assistant reads and edits the open map with you, and Tools ▸ AI lays out maps, writes triggers and briefings, and reviews a map. The prompts are public in ai-engine. See The AI.
  • Triggers as a graph. Trigger Map (Browse Plugins) shows which triggers set and read each switch, death counter and location, and what is never set, read or run.
  • The ground as a unit walks it. View ▸ Walkability (Ctrl+Shift+W) draws islands, regions, chokes with their widths, and distances between start locations.
  • Damaged and protected maps. Repair checks each map as it opens and fixes what the game would; Section Explorer (Browse Plugins) shows the file byte by byte. See Protected and damaged maps.
  • Nothing lost on save. Unknown or malformed sections and unnamed archive files are written back as they were read, unless the game would refuse the map as it stands. See Opening and saving maps.
  • Terrain from a picture. File ▸ Import ▸ Terrain from Image… turns an image into terrain, cliffs and shores included. See Plugins.
  • Stamps. Save a ramp, a bridge or a mineral line once and lay it down on any map. See Cut, copy and paste.
  • Doodads into terrain. Convert Doodad to Terrain turns a doodad into ordinary tiles you can edit. See Doodads.
  • A recording of the build. Timelapse (Browse Plugins) records the map change by change and exports a GIF or WebM video. See Plugins.
  • Maps from scmscx.com. File ▸ Find on scmscx.com… searches the community map archive and opens the map you pick. See Opening a map.
  • Work kept. Maps open in tabs, recovery copies of unsaved work, and the version a save replaced kept as a .bak or under File ▸ Previous Versions. See Saving and Recovery copies.
  • English or Korean. Preferences ▸ General switches the language. See Keyboard and preferences.
