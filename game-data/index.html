Game data

Where the graphics come from, how they are extracted, and what the editor does without them.

A map file holds numbers: a tile id per cell, a unit type per placed unit. The pictures those numbers refer to are in StarCraft's own archives, StarDat.mpq and BrooDat.mpq. That is Blizzard's data, not covered by this project's MIT license and not redistributable, so none of it ships with the editor. The editor gets it from a copy of the game you are entitled to use, extracts what it needs once, and keeps the result.

This document is for anyone who wants to know where the graphics come from, what is kept where, how a mod's files can be used in place of the game's, and how the pictures are drawn. The user guide covers the first-run dialog itself; building the editor from source, which needs the same files on disk, is in Extracting for a source build.
