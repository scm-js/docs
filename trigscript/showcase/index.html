Showcase

Maps made with TrigScript, each with its whole script and a recording of it played in StarCraft: Remastered.

Bad Apple!!#

Watch it on YouTube.

The shadow-art video for "Bad Apple!!" played on the minimap, in time with the song. The fog of war is the screen: a tile lit this frame is white, a tile seen before is grey, so each frame of the game shows one frame of the video, 5,216 of them.

The video is a file of the script. Import Video… turned it into bad-apple.video, 128 × 96 with one tile per pixel, and when the script is built the fog library works out, for every frame, the units whose sight covers exactly its white parts. In the game each of those units is made and taken away in the same trigger pass, and what it saw stays lit until the next frame, when the library has the game put every tile back in fog. A frame takes about 125 units on average and 356 at the most. The language guide describes files the script imports and the fog library.

import { fog } from "trigscript/fog";
import badApple from "./bad-apple.video";

const W = 128, H = 96;
// The camera waits below the board: the minimap draws the camera's box over
// whatever is under it.
const PARK = reserveLocation("bad apple: the camera, below the board");

// Rows `from` to `to` of the board lit, as a picture: one step of the curtain the
// video opens and closes behind.
const band = (from: number, to: number) =>
  fog.picture(Array.from({ length: H }, (_, y) => (y >= from && y < to ? "#" : ".").repeat(W)));
const STEP = 4;
const board = band(0, H);
// White falls over the board from the top, a second long, then slides off the bottom.
const fall = Array.from({ length: H / STEP }, (_, i) => band(0, (i + 1) * STEP));
const lift = Array.from({ length: H / STEP - 1 }, (_, i) => band((i + 1) * STEP, H));

const credits = () => {
  displayText("\x04Bad Apple!! feat. nomico");
  displayText("\x05Alstroemeria Records, after a Touhou Project song by ZUN. Shadow art video by Anira.");
};

program(async () => {
  centerLocation(PARK, 64 * 32, 116 * 32);
  centerView(PARK);
  await sleep(frames(24));
  credits();
  displayText("\x05Played on the minimap with the fog of war, written in TrigScript.");
  for (const p of fall) { fog.light(P1, 0, 0, p); await nextFrame(); }
  let i = 0;
  while (i < 72) { fog.light(P1, 0, 0, board); await nextFrame(); i++; }
  for (const p of lift) { fog.light(P1, 0, 0, p); await nextFrame(); }
  await sleep(frames(12));

  playWav("staredit\\wav\\badapple.ogg", 0);
  await fog.play(P1, badApple);

  // The song runs a little past the last frame.
  await sleep(frames(48));
  for (const p of fall) { fog.light(P1, 0, 0, p); await nextFrame(); }
  displayText("\x04Fin.");
  credits();
  i = 0;
  while (i < 120) { fog.light(P1, 0, 0, board); await nextFrame(); i++; }
  for (const p of lift) { fog.light(P1, 0, 0, p); await nextFrame(); }
});

The for … of loops are written out once per picture when the script is built, so each step of the curtain is a fixed set of units; the while loops run in the game.

The map. 128 × 128 Badlands. The top 96 rows, the picture, are all one tile, 23778, laid with the Tile brush: of the tiles measured, its lit and fogged colours lie furthest apart on the Classic minimap. The 32 rows below have never been seen, so they stay black, and the camera waits there. There are no units, so nothing lights the fog but the script. Player 1 is the human and Player 2 a computer: Remastered will not start a Use Map Settings map without a computer slot.

The song is in the map's archive as a stereo Ogg file, staredit\wav\badapple.ogg, which Remastered plays. Import Video… also takes a sound file, as a .sound file of the script that playWav plays (mixed to mono).

Playing it. Host a multiplayer game alone, which runs at Fastest, the speed the video was imported for. Switch to Classic graphics (Options ▸ Graphics, or F5): Classic draws the minimap sharp, one pixel per tile, where Remastered graphics blurs it. Turn the music volume down, so the game's own music does not play over the song.

"Bad Apple!! feat. nomico" is by Alstroemeria Records, an arrangement of a song from the Touhou Project by ZUN; the shadow-art video is by Anira. Neither comes with the editor or the plugin.

Korobeiniki#

Watch it on YouTube · Download the map (7.9 MB) · The whole script

A falling-block game on the minimap, played with the keyboard, and a band that follows it. The song is Korobeiniki, and its form is decided by the game as it is played: verse and break take turns, a new level brings the build and then the drop, four lines at once bring the drop straight away, a stack grown past two thirds of the well keeps the build going until it is dug down, and from level 4 the last verse, a tone up, takes the verse's place. The pieces fall on the beat, so a piece lands, and its lines go, on the music.

The screen is units. Each cell of the well is an Overlord, and the minimap draws it in its owner's colour, so each piece belongs to a player of its own, given a colour in the map (red, white, green, blue, yellow, teal, purple). The trigscript/screen library keeps the picture: drawing sets cells, and present() takes away and makes only the Overlords whose cell changed. The grey ghost under the piece is the computer's: Remastered's minimap shows no units of Players 9 to 12, and the computer is the one slot that owns no piece. Because a computer moves its own units, and an air unit on the move pushes its neighbours aside, the ghost is taken away before each picture is shown and made again after it, so it never moves.

The music is a trigscript/music song in four layers (drums, bass, harmony, melody), cut into half bars when the script is built. In the game a Band plays the sections, and the script tells it where to go next:

function direct() {
  const s = band.section;
  const base = hud.level >= TONE_UP ? LAST : VERSE;
  if (hud.mode !== PLAYING) {
    // The outro rings out, then the intro, again and again.
    band.loop = s === INTRO;
    if (s === OUTRO) band.queue(INTRO);
    else if (s !== INTRO && band.next !== OUTRO && band.next !== INTRO) band.go(INTRO);
  } else {
    // What the game did, at the next half bar: four lines, the drop; a level, or a
    // stack grown high, the build (and after it, as the song goes, the drop).
    if (tetris && s !== DROP) band.go(DROP);
    else if ((leveled || (high && s !== BUILD)) && s !== DROP && s !== BUILD && band.next !== DROP) band.go(BUILD);
    tetris = false;
    leveled = false;
    // While the stack stays high the build plays again; else each section goes on.
    band.loop = s === BUILD && high;
    if (!(band.now && band.next >= 0)) {
      if (s === INTRO || s === OUTRO) band.go(base);
      else if (s === VERSE || s === LAST || s === DROP) band.queue(BREAK);
      else if (s === BUILD) band.queue(DROP);
      else band.queue(base);
    }
  }
  // No drums in the first verse.
  band.on[DRUMS] = !(hud.mode === PLAYING && hud.level === 0 && s === VERSE);
  hud.music = s;
}

Gravity counts in eighths of a beat from the band's own clock, so a row falls on the beat: every beat and a half at level 1, every eighth of a beat at level 10. One, two or three lines ring a chime of as many notes. The bars right of the well jump on each beat for the layers that begin a note in that half bar.

The map. 64 × 64 Space Platform: the well and the boxes are framed in Platform, the rest is Space, so the minimap shows grey frames on black. Player 1 is the human, Player 2 the computer that owns the ghost, and Players 3 to 8 own the pieces. The script reads the keys through the game itself, so it plays the same alone or hosted.

Playing it. Host a multiplayer game alone and turn the game's music off. A D move, W and Q turn, S drops a row, Space drops all the way, E holds the piece for later. Both graphics modes work; the video is in Remastered.

Korobeiniki is a Russian folk song from the 19th century; the arrangement was made for this map.

Für Elise#

Watch it on YouTube · Download the map (3.8 MB) · The whole script · The soundtrack

Beethoven's Für Elise, begun on a grand piano and carried into a trance remix, with every note drawn as it sounds. The notes fall onto a keyboard twice: on the minimap, where a note is a column of Overlords over Space, and on the main screen, where it is a column of Spider Mines wearing a Flag's looks. The melody is gold and drawn on top, the left hand cyan, and in the drops and builds the rest of the band falls in violet. In the storm, the piece's D minor middle, the chords turn red and the white keys flash red on each one, and Battlecruisers and Wraiths blow up on the biggest beats.

The music is one sound, 2 minutes 35 seconds long, made when the script is built and started with a single playWav. The piano is the Salamander Grand Piano, recordings of a real grand at sixteen strengths for every third key, with the pedal and the strings ringing under it; the strings, crash and timpani are recordings from VSCO 2 Community Edition; the synths and drums are made by the script. The remix is in 4/4 at 128 beats a minute, each bar of the original's 3/8 becoming half a bar. It is mixed with the melody first: the harmony goes down whenever the melody plays, and a check run on the finished sound requires the melody to stand at least 6 dB over everything else in its range in every bar it plays.

const grand = music.sampled(piano, { resonance: 0.07 });
const heard = {
  piano: { instrument: grand, volume: 1.2, reverb: 0.2 },
  lead: { instrument: music.presets.trance(), reverb: 0.25,
          fx: (c) => c.delay(BEAT * 0.75, { feedback: 0.3, mix: 0.18, pingPong: true }) },
  arp: { instrument: music.presets.arp(), pan: 0.25, volume: 0.8, fx: PUMP },
  bass: { instrument: music.presets.bass({ volume: 0.3 }), fx: (c) => PUMP(c.filter("lowpass", 700)) },
  // … pads, stabs, strings, drums, timpani, risers
};
const take = music.perform({ meter: "4/4", bpm: 128 }, parts);
// The harmony 6 dB down under the melody.
const harmony = music.render(take, { parts: HARMONY }).duck(melody, { depth: 6, threshold: -30 });

These sampled instruments are not in the editor's TrigScript yet. The script builds from a checkout of the TrigScript repository, which also holds the tool that turns the piano and orchestra recordings into the .samples files the script imports.

The picture is worked out when the script is built: for every frame, the notes sounding at that moment and where each falls. The program only plays the changes back, a unit made, taken away or handed to the player of its new colour with Give Units, which recolours a unit where it stands. Remastered shows the picture about 95 ms ahead of a sound started in the same frame, so the music starts two frames early. One long sound keeps time with the game: in the recording it matches the file to the sample at every ten seconds, from start to end.

The map. 128 × 128 Space Platform: Space at the top, black on the minimap, for the falling notes, and Platform at the bottom for the stage the camera watches. Player 1 owns only the Map Revealers placed over the map, Player 2 is the computer the game needs and owns nothing (a computer moves its own units), and Players 3 to 8 each own one colour: the white keys, the black keys, the melody, the left hand, the storm and the band.

Playing it. Host a multiplayer game alone, turn the game's music off and leave sound effects on. It plays once, about two and a half minutes.

Beethoven's score is in the public domain; the transcription, from the Breitkopf & Härtel complete edition of 1888, and the remix were made for this map. The piano is the Salamander Grand Piano V3 by Alexander Holm (CC BY 3.0); the strings, crash and timpani are from VSCO 2 Community Edition by Versilian Studios (CC0).
