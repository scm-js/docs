Sections

The sections are listed here in the order StarEdit writes them, and each has a page below in the same order. The last three columns are the game's three reads: needed means the read fails without the section, read that the read uses it when it is there, a number in brackets limits either to the revisions with that VER, and a blank means the read does not use it. A section with no entry in any column is not read by 1.16.1: most are for editors, and a map plays the same without them. Its Read by row says who does read it.

TYPE Which game the file is for

How to read a section's page#

Each page starts with what the section is for, then a table of these rows, where they apply:

Row Says
Name The four characters, and their bytes in hex
Size How long the section is, or how its length follows from the map
Read by Which of the game's reads use it, or that only editors do
Required Whether a map loads without it, and what the player sees when it does not
The game accepts Which lengths the game takes; see Lengths
More than one copy What a second copy does; see Repeated sections
In scmJS Whether this editor models the section or carries its bytes unchanged

The Layout table under it gives each field's offset from the start of the section's data, its type and what it holds, followed by tables of the values a field takes. Some pages end with an Example: real bytes, with what each one means.
