IOWN

StarEdit's own copy of OWNR. The game reads OWNR; StarEdit shows this one. The editor writes both the same, and Check Map warns when a file's two disagree.

Name IOWN (49 4F 57 4E)
Size 12 bytes.
Read by Editors only. The game never reads it.
Required No.
In scmJS Read, and written again when you change what it holds.

Layout:

Offset Type Holds
0 u8 × 12 StarEdit's copy of each player's type, one byte per player slot, Player 1 first
