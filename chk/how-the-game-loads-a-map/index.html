How the game loads a map

StarCraft reads a map up to three times, and each time it reads only the sections it needs then: a short read for the map list, a longer one when a game starts, and one more for the briefing. Before each read it checks VER, which must be 59, 63 or 205. Remastered also takes 64 and 206; see Revisions.

Read When Sections, in the order the game handles them Fails with
Map list When the map list shows the map, when a game is created, and again when it starts VER␠, DIM␠, ERA␠, OWNR, SIDE, STR␠, SPRP, FORC, VCOD Invalid Scenario
Melee start When a game of any type but Use Map Settings starts VER 59 and 63: STR␠, MTXM, THG2, UNIT
VER 205: STR␠, MTXM, THG2, UNIT, COLR		 Error loading scenario file.
Use Map Settings start When a Use Map Settings game starts VER 59 and 63: STR␠, MTXM, THG2, MASK, UNIS, UPGS, TECS, PUNI, UPGR, PTEC, UNIx (if present), UPGx (if present), TECx (if present), PUPx (if present), PTEx (if present), UNIT, UPRP, MRGN, TRIG
VER 205: STR␠, MTXM, THG2, MASK, UNIx, UPGx, TECx, PUNI, PUPx, PTEx, UNIT, UPRP, MRGN, TRIG, COLR		 Error loading scenario file.
Briefing When the briefing room of a Use Map Settings game opens STR␠, MBRF Nothing: the game carries on with no briefing

A read fails at the first section it needs that is missing, or at the first copy of a section that it does not accept. What is read before the failure stays read, but the map goes no further.

The map list read runs every time the list shows the map, again when a game is made with it, and again at the start. So the nine sections it needs are needed by every map, and a map that lacks one is shown in the list but cannot be chosen.

Melee and Use Map Settings#

The game type decides what the second read takes. Melee, and every type except Use Map Settings (Free for All, One on One, Capture the Flag, Greed, Slaughter, Sudden Death, Top vs Bottom and the team types), reads four sections: the strings, the terrain, the sprites and the units, plus the colours in a Brood War file. It never reads the map's triggers, locations, fog, unit settings, upgrades, technologies or availability.

Of the placed units, a melee game keeps only the start locations and the mineral fields, geysers and critters of Player 12. Of the unit sprites in THG2, it keeps only Player 12's. Every other unit is left out.

Use Map Settings reads everything else that matters to play.

What a map needs#

The smallest file each kind of game will load:

A map for Needs
Melee and the other game types VER, DIM, ERA, OWNR, SIDE, STR, SPRP, FORC, VCOD, MTXM, THG2 and UNIT, and COLR in a Brood War file (VER 205). Remastered also needs TRIG, and takes STRx in place of STR in a VER 64 or 206 file.
Use Map Settings All of those, and MASK, PUNI, UPRP, MRGN, TRIG and five settings tables: UNIx, UPGx, TECx, PUPx and PTEx in a Brood War file (VER 205 or 206); UNIS, UPGS, TECS, UPGR and PTEC in a VER 59, 63 or 64 file

THG2 can be empty when the map has no sprites. Everything else is optional or for editors. MBRF, the briefing, is not needed: without it there is no briefing and nothing else changes. TYPE is looked for but never read.

When a map will not load#

What a player sees, and what causes it:

The player sees When Why
Invalid Scenario, with "This scenario is unreadable because it is invalid or corrupted." In the map list The map list read failed, and the file's VER is 59 or lower, or could not be read at all. Any fault gives this message in a StarCraft 1.00 file.
Invalid Scenario, with "This scenario is intended for use with a StarCraft Expansion Set." In the map list The map list read failed, and the file's VER is above 59. That covers a Brood War map in the original StarCraft, but also every other fault: a missing DIM, a SIDE of the wrong length, a failed VCOD check, a VER the game does not know such as Remastered's 64 and 206, and in Remastered a missing TRIG, a CRGB of the wrong length or a DIM above 256. The game names the expansion set whatever the real fault. Remastered gives the same message.
"This map can only be played with the 'Use Map Settings' game type." Making a game The tileset is Installation and the game type is not Use Map Settings. Installation maps can only be played as Use Map Settings.
"Error loading scenario file." Starting a game A section this game type needs is missing, the wrong length, or runs past the end of the file. Melee needs MTXM, THG2, UNIT and, in a Brood War file, COLR; Use Map Settings also needs MASK, PUNI, UPRP, MRGN, TRIG and the settings tables. The same map may still start as melee.
"WARNING: Unit unplaceable! (name) (x,y)" The first moments of a game A placed unit had no room where it stands, and was removed. Remastered gives the same warning.
No briefing The briefing room MBRF is missing or not a whole number of records.
The file name in place of the map's name In the map list The name in SPRP is string 0, or an empty string.

Where Remastered differs#

What this page says about the game describes StarCraft: Brood War 1.16.1, the last version before Remastered. Remastered's own loader has been studied the same way, and twelve of the test maps played in it. It reads a map almost exactly as 1.16.1 does: the same walk through the sections, the same reads in the same order, the same lengths and the same rules for repeated sections. These are the differences.

Two more revisions. Remastered also knows VER 64 and 206, the two revisions that can carry the STRx string table. A 206 file is read like a Brood War 205 file and needs Brood War. A 64 file is read like a hybrid 63 file and does not. See Revisions.

The map list reads two more sections, in a file of any revision:

  • TRIG, which every map now needs. The game looks through the triggers for EUD triggers, Deaths conditions and Set Deaths actions that reach outside the table of death counts, and marks the map as using them. A map with no TRIG, or a TRIG that is not whole triggers, is Invalid Scenario whatever the game type. 1.16.1 lists such a map and plays it as melee.
  • CRGB, the player colours, when the file has one. A CRGB that is not exactly 32 bytes makes the map Invalid Scenario.

The map list refuses more. A DIM width or height above 256 is Invalid Scenario, where 1.16.1 does not look at the values. So is a 64 or 206 file that ends up with no string table: one with neither STR nor STRx, or only copies too short to be taken.

Strings:

  • A STR copy shorter than 2 bytes, or a STRx copy shorter than 4, is passed over, and the table before it stays. 1.16.1 takes a copy of any length.
  • In a 64 or 206 file the game reads every STR copy and then every STRx copy, so a STRx wins whatever the order in the file. In any other revision STRx is never read.
  • Each string is read as UTF-8 if its bytes are valid UTF-8, then as Korean (CP949) if they pass a Korean test, and as Windows-1252 otherwise. This holds for STR and STRx alike. 1.16.1 reads every string in the code page of the machine it runs on. The Korean test is loose: it passes whenever every byte above 127 is followed by a byte that could be the second half of a Korean character, so some Windows-1252 text in Western languages shows as Hangul (see STR). (Read in Remastered's code and found playing an English copy of it.) UTF-8 text reads the same everywhere.
  • A string number past the count, or an offset outside the section, gives no text: a map whose last string table held no strings was listed with <MISSING> for its name and description. (Found playing Remastered.) 1.16.1 reads whatever lies past the table in memory.
  • The map list shows the whole name and description, where 1.16.1 cuts them at 31 and 255 bytes. The lobby keeps 31 bytes of the name, counted in UTF-8. See STR. (Found playing Remastered.)
  • A colour code carries on to the next line of the same string, where 1.16.1 starts each line in the default colour again. (Found playing Remastered.)

Colours. COLR values of 12 and up are skipped, where 1.16.1 gives a wrong colour. Remastered also reads the player colours in CRGB, in a file of any revision. A Custom entry gives the player its own colour in every revision played (VER 63, 205 and 206). In a Brood War file a player that CRGB sets to Palette shows its COLR colour; in a VER 59, 63 or 64 file, which has no COLR to read, it shows the colour number in its CRGB entry. Random and Player choice gave those players a different colour in each game of a VER 63 file. (Found playing Remastered.)

Smaller limits:

  • Only the first 65,536 bytes of MASK are used, one for each tile of a 256 × 256 map. 1.16.1 has no limit.
  • A start location in UNIT owned by a player above Player 8 is ignored.
  • A negative section length that jumps back past the start of the file ends the walk there. 1.16.1 reads on from memory outside the file.

These rules are the same in Remastered. Its loader shows all of them, and the test maps confirmed the first nine:

  • a section one byte too long, or a UNIT section that ends in part of a record, refuses the map with the same message;
  • a StarCraft 1.00 file with 255 locations, and a map with no MASK, start as melee and stop as Use Map Settings;
  • a Brood War file with no COLR stops at the start of any game;
  • start locations come from the last UNIT section;
  • a Ghost placed cloaked starts cloaked only if its owner has Personal Cloaking;
  • a hybrid file's UNIx is applied over its UNIS;
  • a section the game never reads may run past the end of the file;
  • the rules for User Selectable races in SIDE and for empty player slots in UNIT;
  • a unit placed where it has no room is removed, with the warning Unit unplaceable;
  • a melee game keeps only the start locations and Player 12's resources and critters;
  • VCOD is checked against the same table, with the same operations;
  • MRGN must be 1280 bytes in a 1.00 file and 5100 in every later one, VER 64 and 206 included;
  • the settings tables have the same lengths, and repeated copies combine entry by entry.

A map with no MBRF plays with no briefing, as in 1.16.1. That one rests on playing alone.

Remastered's trigger engine has been read too, apart from the part that hands out the triggers to the players when a game starts, which is scrambled. The trigger reference lists what it does the same as 1.16.1 and what it does differently. Three trigger checks played in Remastered gave the 1.16.1 result: Create Unit for Player 12 makes nothing, Set Deaths for Player 10 changes nothing in a map with no EUD triggers, and Bring finds nothing in a location whose right edge is left of its left edge.

Still open: the CRGB colours have been played only alone, never in a game with more than one human player, and Random and Player choice only in a VER 63 file.

A map that 1.16.1 accepts, that has a TRIG section, and whose CRGB (if it has one) is 32 bytes long, is the safe target.
