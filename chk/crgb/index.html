CRGB

StarCraft: Remastered's player colours. For each of Players 1 to 8, how its colour is chosen, and three bytes that go with it. Remastered reads it for the map list, in a file of any revision:

  • Random gives the player a random colour.
  • Player choice leaves the colour to the player in the lobby.
  • Custom uses the three bytes as red, green and blue.
  • Palette gives the player a colour from the palette. Any mode above 3 counts as Palette.

Which palette colour depends on the revision. The third byte of a Palette entry is a colour number from the table under COLR, 0 to 21, and the lobby shows it; it shows a Custom entry as Map specified. In a Brood War file (VER 205 or 206) the game then applies COLR over it: a VER 206 test map whose Palette entries said Blue, Orange and Pink played with every player in its COLR colour. A VER 59, 63 or 64 file has no COLR to read, so there the third byte is the player's colour: a Hybrid test map's Palette entry saying Orange played orange. scmJS writes the COLR colour into the third byte, so the two agree in every revision, and in a VER 59, 63 or 64 file it writes CRGB whenever a colour is not the slot's own, since that is the only way those colours reach the game. StarCraft 1.16.1 reads neither section in those files.

Custom was checked in a game, in VER 206, 205 and 63 files: the player's units took the stored colour. So Custom is the way to give a player one of Remastered's colours past the first twelve, or any other colour. Random and Player choice were played in a VER 63 file: the lobby showed both as Random, Player choice as a list the player can change, and each game gave those players a different colour, once black, one of the colours past the first twelve.

All of these were single-player games against computers (found playing Remastered). What a game with several people does with Random, Player choice and Palette entries has not been played.

Name CRGB (43 52 47 42)
Size 32 bytes.
Read by StarCraft: Remastered only, for the map list, in a file of any revision. 1.16.1 does not know it.
Required No.
The game accepts Exactly 32 bytes. Any other length shows the map as Invalid Scenario.
More than one copy The last copy replaces the others. Every copy must still be the right size, or the map is refused.
In scmJS Read, and written again when you change what it holds.

Layout:

Offset Type Holds
0 u8 × 24 Red, green and blue for each of Players 1 to 8, three bytes each
24 u8 × 8 How each player's colour is chosen (modes, below)

Colour modes:

Value Meaning
0 Random
1 Player choice
2 Custom
3 Palette
