The desktop app

The releases page has the installers. These links always point at the newest numbered release:

System Download
Windows, installer scmJS-windows-x64-setup.exe
Windows, zip to unpack and run scmJS-windows-x64.zip
macOS, Apple silicon scmJS-macos-arm64.dmg
macOS, Intel scmJS-macos-x64.dmg
Linux, AppImage scmJS-linux-x86_64.AppImage
Linux, Debian and Ubuntu scmJS-linux-amd64.deb

The app looks for a StarCraft installation on its own, registers .scm, .scx and .chk so a double-click opens a map, and starts the game for Test Map.

Windows#

The installer and the app are not code-signed, so Windows shows a SmartScreen screen saying the app is unrecognized. Choose More info, then Run anyway. The zip needs no installation: unpack it anywhere and run scmJS.exe.

macOS#

Open the dmg and drag scmJS into Applications. macOS refuses to open an app that is not code-signed, so clear the quarantine flag once, in Terminal:

xattr -dr com.apple.quarantine /Applications/scmJS.app

Linux#

Make the AppImage executable and run it:

chmod +x scmJS-linux-x86_64.AppImage
./scmJS-linux-x86_64.AppImage

Or install the .deb:

sudo apt install ./scmJS-linux-amd64.deb

Updates#

The app checks for a new version when it starts (a preference, on by default) and when you choose Help ▸ Check for Updates…. A new version shows up as a notice with a Download button. Nothing downloads or installs until you ask, and installing asks about unsaved maps first, as closing the window does.

  • Windows, the AppImage and the .deb install the update themselves.
  • macOS cannot replace an app that is not code-signed, so the app offers the release page instead.

A preference lets the app follow the nightly builds instead of the numbered releases. After an update, a notice offers the list of what changed; Help ▸ What's New… shows it at any time. The browser editor does the same.

Where it keeps its files#

The app's data folder holds the graphics it extracted, the window's size and position, and startup.log, a record of the last launch:

System Folder
Windows %APPDATA%\scm-js
macOS ~/Library/Application Support/scm-js
Linux ~/.config/scm-js

If the app is slow to open, or opens and shows nothing, startup.log says how long each step of the launch took; attach it to a bug report. Deleting the gamedata folder inside makes the app look for StarCraft again at the next start.
