The graphics

The editor draws terrain and units with graphics out of StarCraft's own files. Blizzard's data is not redistributable and none of it ships with the editor, so on first use the Game Data dialog asks where to get it:

The recommended route is your own StarCraft installation, classic (1.16) or Remastered. If you have neither, Blizzard's free map editor download is enough to edit maps and watch replays. What each route gives you:

Route Editing Remastered graphics Test Map and playing Replays
Your StarCraft: Remastered folder Yes Yes Yes Yes
Your classic StarCraft (1.16) folder Yes No, but can be added Yes Yes
Blizzard's map editor download Yes No No Yes

Test Map and playing means Tools ▸ Test Map, which hands the map to the installed game, and Tools ▸ Test Map in Browser at scmjs.dev, which plays it on the site's play page from your own StarCraft files. Neither works from the map editor download. Replays means File ▸ Open Replay… and watching the game play back.

If the editor was opened from a link (a shared map to join, or a copy of a map), that link is handled first, and the question about the graphics follows.

Use your StarCraft installation#

This is the card marked Recommended at the top of the dialog.

  • In the browser, choose Choose the StarCraft folder… and pick the folder the game is installed in, usually C:\Program Files (x86)\StarCraft. The browser asks whether to upload the folder. Nothing leaves your computer: the editor only reads the files.
  • In the desktop app, there is nothing to do if the game is where its installer put it: the app finds it at start. Otherwise choose Search this computer, or Choose the StarCraft folder… to point at it yourself.

Classic or Remastered is told from the folder. A Remastered folder turns on View ▸ Remastered Graphics, which you can untick at any time for the classic look; the guide's Classic or Remastered graphics shows the difference.

The editor copies what it needs and keeps it, so this happens once. In the browser the copy also keeps the files the site's play page runs the game from, so the game is set up once for both. The tick box Keep the files for real-time lighting on the play page adds what the play page needs to light units as Remastered does, about 200 MB more. Rough sizes of the copy:

Copy Browser Desktop app
From a classic (1.16) installation or the download about 140 MB about 30 MB
From a Remastered installation about 650 MB about 365 MB
From Remastered, with the lighting files about 850 MB —

Reading a Remastered installation takes under a minute.

No StarCraft installed?#

The lower part of the dialog has two ways in without an installation:

  • Download from Blizzard — 83 MB. Blizzard offers its standalone StarCraft map editor as a free download, and the package carries the files the graphics come from. No account, nothing to find on your own disk. The editor fetches only the parts it needs.
  • Choose StarDat.mpq and BrooDat.mpq… (browser only). Pick the two archives yourself, from the map editor download or from a classic installation's folder.

A copy made from the map editor download is enough to edit maps and watch replays. Testing a map or playing needs StarCraft installed. Once you have it, open Help ▸ Game Data…, choose Remove copy, and choose the StarCraft folder when the dialog asks again; for Remastered, Add StarCraft: Remastered… also works, as below.

Remastered graphics#

Choosing a Remastered folder in the first place is all it takes: the editor reads the Remastered graphics with the rest and turns them on.

If you installed from a classic copy or the map editor download first and get Remastered later, open Help ▸ Game Data… and choose Add StarCraft: Remastered… under Data sets. It is installed beside the copy you have, and the Data sets list switches between the two.

Remastered added tiles, and so doodads, to most tilesets. A map that uses them needs the Remastered files to be drawn; from a classic copy those tiles have no picture.

Changing it later#

Help ▸ Game Data… brings the dialog back. It shows where the graphics come from now, and lets you:

  • remove the copy (Remove copy), after which the dialog offers the routes above again;
  • install a data set, a mod's files beside the game's, and switch between them (see Data sets);
  • add StarCraft: Remastered beside a classic copy, as above.

At scmjs.dev, scmjs.dev/editor/data lists every copy the browser holds, with where it came from and how large it is.

Without any graphics the editor still runs: terrain is drawn in flat colours and units as coloured markers, and everything else works.
